# 🎭 Emotion to Meme Generator

**一个基于 Vue 3 + face-api.js + Spring Boot 的实时情绪识别与表情包生成器**

## 🎯 功能

- 实时摄像头人脸检测与情绪识别（快乐/悲伤/愤怒/惊讶/恐惧/厌恶/平静）
- 自动匹配情绪并生成个性化表情包

## 📌 项目简介

传统表情包使用需要手动搜索和挑选，缺乏个性化和实时性。本项目通过人脸情绪识别技术，让用户只需面对摄像头做一个表情，系统就能**自动识别当前情绪并生成匹配的专属表情包**，实现“表情即情绪”的即时表达。

### 🎯 核心功能

- **实时人脸检测**：通过摄像头捕捉人脸，识别 7 种基础情绪（开心、悲伤、愤怒、惊讶、恐惧、厌恶、平静）
- **情绪匹配文案**：根据识别结果自动匹配对应的表情包文案
- **一键生成表情包**：将人脸区域与文案合成，生成可保存的图片
